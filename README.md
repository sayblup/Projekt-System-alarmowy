# Projekt-System-alarmowy
Celem projektu jest opracowanie systemu alarmowego opartego na platformie Arduino. System powinien umożliwiać obsługę wielu czujników, dodawanie nowych czujników z poziomu menu, wyświetlanie interfejsu użytkownika na wyświetlaczu LCD, a także prezentację stanu alarmu na panelowym wyświetlaczu LED.
